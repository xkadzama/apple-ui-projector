# Чистый проектор — базовый список для проекторов на Android TV / Google TV 13+
#
# Применение:
#   TV_HOST=192.168.1.50 python3 tools/debloat.py lists/projector-generic.txt --dry-run
#   TV_HOST=192.168.1.50 python3 tools/debloat.py lists/projector-generic.txt
# Возврат:
#   TV_HOST=192.168.1.50 python3 tools/restore.py
#
# ЭТО ШАБЛОН, А НЕ ИСТИНА. Пакеты у каждого бренда свои: сначала запустите
#   python3 tools/discover.py
# — он покажет, что реально стоит на ВАШЕМ проекторе, и соберёт список под него.
# Этот файл задаёт только то, что встречается почти у всех: реклама Google, телеметрия,
# предустановленный мусор. Всё это НЕ удаляется, а отключается (pm disable-user).
#
# Ниже намеренно НЕ отключено ничего из того, что относится к самому проектору:
# коррекция трапеции, автофокус, HDMI-вход, Bluetooth-пульт, экранная клавиатура,
# Play Store, Play Services, Wi-Fi. Эти пакеты трогать нельзя — проектор станет
# «умным экраном без картинки».
