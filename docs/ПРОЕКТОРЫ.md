# Проекторы против телевизоров: что отличается

Проектор на Android TV — это тот же Android, но с другим «железом» и другими рисками.
Если чистить его теми же списками, что телевизор, можно остаться с «умной приставкой
без картинки».

## Чего у проектора нет

| Есть у телевизора | У проектора |
|---|---|
| Тюнер DVB-C/T/S, каналы, «Прямой эфир» | как правило, нет — `live_tv_package` оставляем пустым |
| Список входов HDMI 1–4 | один HDMI (иногда два), плюс AV |
| Аудиосистема с сабвуфером | встроенный динамик, иногда Bluetooth-выход |
| Пульт с кнопками каналов | пульт с кнопкой фокуса/трапеции |

Поэтому в `launcher/app/src/main/res/values/config.xml` по умолчанию:

```xml
<string name="live_tv_package" translatable="false"></string>
```

Это убирает пункт «Прямой эфир» из меню входов — на проекторе ему нечего открывать.

## Чего у проектора в избытке

Это пакеты, которых на телевизоре не бывает, и отключать их нельзя:

| Что | Как выглядит в именах пакетов | Что будет, если отключить |
|---|---|---|
| Коррекция трапеции | `autokst`, `keystone`, `trapezoid` | картинка станет трапецией, поправить пультом не выйдет |
| Автофокус | `tof`, `autofocus`, `focus` | изображение расплывётся |
| Оптика и мотор | `motor`, `zoom`, `optical`, `lens` | зум и фокус перестанут работать |
| Охлаждение | `fan`, `thermal`, `cool` | перегрев, аварийное отключение |
| Лампа/лазер | `lamp`, `laser`, `dmd` | не запустится источник света |

`tools/discover.py` относит всё это к категории **«НЕ трогать — железо проектора»** и не
включает в список. Если такой пакет всё же попал в список вручную, `debloat.py` применит
его — фильтр по железу есть только в разведке, не в применении. Поэтому список стоит
собирать через `discover.py --write`, а не писать с нуля.

## Стоковый лаунчер, который возвращается

На проекторах XGIMI (MoGo 3 Pro, MoGo 4, Horizon) стоковый лаунчер
`com.google.android.apps.tv.launcherx` после отключения **включается сам** — при перезагрузке
и даже во время работы. Это делает системный сервис бренда (`com.xgimi.xrmservice`).

Что с этим делать:

1. **Не отключайте его повторно после каждой загрузки** — это борьба с симптомом.
2. Используйте перенаправление Home в настройках лончера:

```json
{ "stock_home_redirect": "com.google.android.apps.tv.launcherx" }
```

Это говорит «Дому» перехватывать кнопку Home, даже когда стоковый лаунчер жив.

3. На некоторых прошивках для этого нужен `HomeKeyService`:

```bash
TV_HOST=192.168.1.50 HOME_KEY_SERVICE=1 ./install_launcher.sh
```

**Цена:** на прошивках XGIMI это ломает автоповтор кнопок громкости (удержание = один шаг
вместо плавного изменения). Кнопки направления продолжают повторяться нормально.

## Отладка только по Wi-Fi

Многие проекторы (MoGo 4 и другие) не имеют USB-порта для ADB вообще. В меню разработчика
у них только «Wireless debugging», и порт 5555 открывается вместе с ним, а после перезагрузки
закрывается.

Отсюда: **вся работа делается за один сеанс**. Если проектор ушёл в сон или перезагрузился —
включайте отладку заново и начинайте с `python3 tools/adb.py --discover`.

## Нестандартные порты

Проекторы иногда слушают ADB не на 5555. Известный случай — 5877. Поэтому `--discover`
проверяет несколько портов, а `TV_PORT` позволяет указать свой:

```bash
TV_PORT=5877 TV_HOST=192.168.1.50 python3 tools/adb.py --probe
```

## Скриншоты

`screencap` на проекторе иногда возвращает пустоту на HDMI-входе — это нормально для
защищённого контента, а не признак поломки. Если снимок пустой, проверьте, что происходит:

```bash
python3 tools/adb.py 'dumpsys activity activities' | grep -i ResumedActivity
```

На некоторых прошивках `screencap -p` дописывает в начало файла строку от вендора —
`tools/adb.py` сам находит сигнатуру PNG и обрезает мусор.

## Разрешение и плотность

Проекторы часто работают в 1280×720 или 1920×1080 с нестандартной плотностью. Если после
установки лончера картинка кажется увеличенной, проверьте:

```bash
python3 tools/adb.py 'wm size'
python3 tools/adb.py 'wm density'
```

Если видите значение «Override» — оно могло остаться от эксперимента с разрешением.
Вернуть: `wm size reset` и `wm density reset`.
