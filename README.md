# Чистый проектор

Приведение проектора на **Android TV 13** к виду «как на Apple TV»: без рекламных рядов,
телеметрии и предустановленного мусора, с чистым домашним экраном вместо стокового.

Сделано по мотивам [Gathin23/cleanyourtv](https://github.com/Gathin23/cleanyourtv) (MIT),
но под проектор, а не телевизор: у проекторов нет тюнера, зато есть оптика, трапеция и
автофокус, которые нельзя отключать случайно.

> **Ничего не удаляется.** Пакеты отключаются через `pm disable-user` — то же самое, что
> «Отключить» в Настройки → Приложения. Любое изменение откатывается одной командой.

---

## Что нужно

| Что | Зачем |
|---|---|
| Проектор на Android TV 13 (Google TV) | тот самый, который чистим |
| Компьютер в той же Wi-Fi сети | Mac, Windows или Linux, Python 3.8+ |
| `openssl` | подпись ключа ADB. На macOS уже есть. Linux: `apt install openssl` |

Ничего устанавливать в систему не нужно: все инструменты — обычный Python без зависимостей.

---

## Шаг 1. Включить отладку на проекторе

1. **Настройки → Система → О проекторе** (у разных брендов: «Об устройстве», «Справка»).
2. Найдите **«Сборка»** / **Build** и нажмите OK **7 раз**. Появится «Вы стали разработчиком».
3. Назад в **Настройки → Система → Для разработчиков**.
4. Включите **«Отладка по ADB»** (может называться «Отладка по USB», «Отладка по сети»,
   «Network debugging»). Если есть отдельный переключатель **«Отладка по сети»** — включите и его.
5. Оставьте проектор включённым.

> На некоторых проекторах отладка включается только с флешки/через сервисное меню.
> Если пункта нет — скажите, разберёмся с вашей моделью отдельно.

---

## Шаг 2. Найти проектор в сети

```bash
python3 tools/adb.py --discover
```

Скрипт просканирует вашу подсеть на порты ADB (5555, 5877 и другие, которые используют
проекторы) и покажет модель, версию Android и прошивку. Запомните адрес:

```bash
export TV_HOST=192.168.1.50
export TV_PORT=5555        # если --discover показал другой порт
```

Если нашлось несколько устройств — проектор будет помечен словом **ПРОЕКТОР**.

**На экране проектора появится запрос «Разрешить отладку?»** — нажмите «Разрешить» пультом
и поставьте галочку «Всегда разрешать с этого компьютера».

Проверка:

```bash
python3 tools/adb.py --probe
```

---

## Шаг 3. Бэкап — до любых изменений

```bash
python3 tools/backup.py
```

Сохраняет в `~/.projector/backups/<дата>/`: все пакеты, уже отключённые пакеты, `getprop`,
настройки и текущий домашний экран. Позже `tools/restore.py` вернёт всё ровно как было.

Посмотреть, что изменилось с тех пор:

```bash
python3 tools/backup.py --diff
```

---

## Шаг 4. Разведка: что стоит именно на вашем проекторе

```bash
python3 tools/discover.py
```

Скрипт **ничего не меняет**. Он раскладывает установленные пакеты по полочкам:

- **Безопасно отключить** — реклама Google, телеметрия, демо-режим, предустановленный мусор;
- **Отключить по желанию** — стриминги, голосовой ассистент, обновления прошивки;
- **НЕ трогать — железо проектора** — трапеция, фокус, HDMI, пульт, звук;
- **Неизвестные** — посмотреть, что это: `python3 tools/discover.py --explain <package>`.

Собрать список под свою модель:

```bash
python3 tools/discover.py --write          # всё, что скрипт считает лишним
python3 tools/discover.py --write --safe   # только очевидное, без стримингов и голоса
```

Результат — `lists/<модель>-debloat.txt`, обычный текстовый файл, который можно править руками.

## Шаг 5. Применить список

Сначала посмотреть план, ничего не меняя:

```bash
python3 tools/debloat.py lists/projector-generic.txt --dry-run
```

Затем применить:

```bash
python3 tools/debloat.py lists/projector-generic.txt
```

Что защищает от «кирпича»:

| Защита | Что делает |
|---|---|
| **Ядро Android** | отказывается отключать `systemui`, `settings`, провайдеров, ТВ-middleware — с ними устройство не загрузится |
| **Home guard** | не отключает владельца кнопки Home, пока новый лончер не стал домашним |
| **Мастер настройки** | не отключает `setupwraith`, если сохранённая Wi-Fi сеть принадлежит ему (иначе проектор потеряет сеть и ADB) |
| **Чужое не трогаем** | пакеты, отключённые вами раньше, остаются отключёнными |
| **Проверка результата** | после каждого пакета читает `pm list packages -d` и сообщает, что не встало |

Порядок применения — по одному пакету, а не пачкой: если что-то пойдёт не так, видно, что именно.

## Шаг 6. Новый домашний экран (опционально)

Стоковый экран Google TV — это рекламные ряды и «рекомендации». Вместо него ставится
маленький нативный лончер в стиле Apple TV: чёрный фон, док из четырёх приложений,
сетка приложений, часы и стеклянные кнопки входа/сети/настроек.

### 6.1. Поставить JDK 17 и Android SDK (один раз)

```bash
./setup_toolchain.sh
```

Скрипт проверит, что уже установлено, поставит через Homebrew `openjdk@17` и
`android-commandlinetools`, примет лицензии и добавит `platforms;android-34` с
`build-tools;34.0.0`. Скачивается ~700 МБ — на медленной сети это может занять время,
запускать можно в фоне:

```bash
nohup ./setup_toolchain.sh > setup.log 2>&1 &
tail -f setup.log
```

Если ставите вручную — нужны именно эти версии, их читает `launcher/app/build.gradle`:

```bash
brew install openjdk@17 android-commandlinetools
sdkmanager --licenses
sdkmanager "platforms;android-34" "build-tools;34.0.0"
```

JDK новее 22 не подойдёт: Gradle 8.9 падает с `Unsupported class file major version`.

### 6.2. Собрать и поставить

```bash
TV_HOST=192.168.1.50 ./launcher/install_launcher.sh
```

Скрипт по порядку: проверяет, что SDK проектора не ниже `minSdk` лончера (иначе `pm install`
ответит `INSTALL_FAILED_OLDER_SDK` ещё до сборки); собирает APK; ставит его; назначает
домашним экраном; **проверяет через `dumpsys activity`, что Home действительно открывает
новый экран**; и только после этого отключает стоковый лаунчер — а если Home не переключился,
сразу включает его обратно.

Собрать отдельно, поставить потом:

```bash
cd launcher && ./gradlew assembleRelease
TV_HOST=192.168.1.50 SKIP_BUILD=1 ./install_launcher.sh
```

Если собираете `gradlew` вручную, укажите SDK — файла `local.properties` в репозитории
нет (он машинно-зависимый, `install_launcher.sh` создаёт его сам):

```bash
export JAVA_HOME=$(brew --prefix openjdk@17)
export ANDROID_HOME=$(brew --prefix android-commandlinetools)
cd launcher && ./gradlew assembleRelease
```

### 6.3. Настроить под себя

Приложения в доке — `launcher/app/src/main/res/values/config.xml`, блок `dock_apps`
(по умолчанию YouTube, Netflix, Кинопоиск, Иви). Скрытые приложения — блок `hidden_apps`.
После правки — пересобрать и запустить `install_launcher.sh` снова.

Вернуть стоковый экран: `python3 tools/restore.py --home`.

---

## Шаг 7. Проверить и закрыть

```bash
python3 tools/backup.py --diff      # что изменилось
python3 tools/adb.py --screenshot shot.png   # снять экран проектора
```

Когда всё устраивает — **выключите отладку по ADB** на проекторе (Шаг 1, п.4) и проверьте,
что порт закрыт:

```bash
python3 tools/adb-closed.py 192.168.1.50
```

Порт 5555 работает по открытому тексту. Если `ro.adb.secure=0` (некоторые прошивки),
любое устройство в вашей сети получает доступ к проектору без запроса — держать его
включённым постоянно нельзя.

---

## Как всё вернуть

```bash
python3 tools/restore.py              # включить обратно всё, что отключили мы
python3 tools/restore.py --list       # сначала посмотреть план
python3 tools/restore.py --home       # только вернуть стоковый домашний экран
python3 tools/restore.py --only com.google.android.feedback   # один пакет
```

Пакеты, отключённые до нас, не включаются — они остаются как были.

Если проектор вообще не отвечает по ADB, вернуть пакеты можно с пульта:
**Настройки → Приложения → Показать системные → нужное приложение → Включить**.

## Что сделано на этом проекторе

Подробности и находки — в [`docs/УСТРОЙСТВО-smart-project.md`](docs/УСТРОЙСТВО-smart-project.md).
Кратко: Android 13 (SDK 33), платформа DroidLogic, 135 пакетов, отключено 12 (реклама Google,
атрибуция, сторонние магазины, синхронизация). Проверено перезагрузкой: состояние держится,
лаунчер и Wi-Fi работают.

**Важно:** на этом устройстве ADB сразу выдаёт `root` (в системе есть SuperSU). Пока включена
отладка, любой в сети получает полный контроль над проектором. После работы выключите отладку
и проверьте: `python3 tools/adb-closed.py <ip>`.

## Частые проблемы

| Симптом | Что делать |
|---|---|
| `--discover` ничего не нашёл | отладка по ADB не включена; проектор в другой сети (гостевая Wi-Fi); включён VPN на компьютере |
| Проектор найден, но `pm` не работает | нажмите «Разрешить» на экране проектора; на macOS разрешите терминалу доступ к локальной сети (Системные настройки → Конфиденциальность → Локальная сеть) |
| Порт открыт, но ADB молчит | у проектора может быть свой порт: `TV_PORT=5877 python3 tools/adb.py --probe` |
| После перезагрузки всё вернулось | некоторые прошивки восстанавливают пакеты сами; см. `docs/ПРОЕКТОРЫ.md` |
| Home открывает пустой экран | включите стоковый лаунчер: `python3 tools/restore.py --home` |
